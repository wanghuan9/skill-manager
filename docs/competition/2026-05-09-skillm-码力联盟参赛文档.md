# skillm 码力联盟参赛文档

## 一、背景

AI 编程工具越来越多，不同工具的 Skill 目录、MCP 配置和安装方式都不一样，团队在使用时经常要重复安装、重复同步、重复配置。

`skillm` 想解决的就是这个问题：把 Skill、MCP 和工具配置统一放到一个桌面应用里管理。

## 二、价值

- 降低使用门槛，用户不用再分别研究各个工具的配置方式。
- 提升复用效率，团队沉淀的 Skill 可以统一安装、统一同步。
- 减少重复操作，把 Skill 管理、MCP 管理、工具接入放到同一个工作台里完成。

## 三、难点

- 不同 AI 工具的 Skill 路径和 MCP 配置格式都不一样，接入成本高。
- Skill 和 MCP 的来源很多，既有市场，也有 Git 仓库和本地目录，统一管理不容易。
- 既要保证功能完整，又要让产品足够简单，方便普通开发者使用。

## 四、创意

- 用一个本地桌面应用统一管理 `Skill + MCP + 工具` 三类能力。
- 安装页把 Skill 和 MCP 放在同一入口，符合真实 Agent 使用场景。
- 既支持市场安装，也支持 Git 安装和本地导入，适合团队内部沉淀和分发。

一句话总结：`skillm` 是一个面向 AI 开发场景的本地能力工作台，让分散在不同工具里的 Skill 和 MCP，变得更容易安装、更容易同步、更容易管理。
