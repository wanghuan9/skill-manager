本版本对比 `v0.1.20`，重点完善了跨平台发布、真实 Skill 目录管理、卡片式布局、深色主题和本地修改协作体验。

## 新增

### Windows 与自动更新

- 正式提供 Windows x64 NSIS 安装包，并支持 Windows 自动更新和更新签名校验。
- Windows 新增适配无框窗口的最小化、最大化、还原和关闭按钮。
- macOS 后续专注支持 Apple Silicon，不再发布 Intel 安装包。

### 显示并管理各工具真实目录中的 Skill

- 新增 Skill 来源视图，可直接查看 Claude Code、Codex、Cursor、Windsurf、Gemini CLI、VS Code、IntelliJ IDEA 等已安装工具真实 Skill 目录中的内容。
- 自动识别 Skill 是 SkillDock 已托管、未托管还是与托管版本冲突，并区分真实文件夹与符号链接。
- 支持查看 Skill 的所在软件、真实目录、托管目录、文件类型和简介，并可直接打开目录或预览实际文件。
- 支持把工具目录中的未托管 Skill 导入 SkillDock，也可只从当前工具中移除 Skill。
- 对已托管 Skill 支持一键定位到 SkillDock 托管版本。
- 来源视图支持按托管状态筛选、按名称/描述/路径搜索，并支持列表与卡片两种展示方式。

### 卡片式布局与界面主题

- Skills、MCP 和插件页面新增卡片视图，并保留列表视图；卡片可直接查看状态、启用工具和主要操作，详情通过弹窗展开。
- 新增全局卡片样式偏好，可统一设置 Skills、MCP 和插件的默认布局，各页面之后仍可独立切换。
- 新增管理页头布局设置，可在横向来源导航和紧凑来源选择之间切换。
- 新增完整深色主题，支持浅色、深色和跟随系统，并记忆用户选择。

### 本地修改与差异预览

- 新增“待提交”状态和筛选，可直接识别存在未提交修改的 Git Skill。
- 新增本地修改文件树，显示新增、修改、删除以及已暂存、未暂存状态。
- 新增可编辑的 Diff 预览，可在“只看变动”和“查看全部”之间切换，并显示真实行号和上下文。
- 支持直接编辑并保存发生修改的文件，也支持按文件或按变更块回退本地修改。
- Skill 列表详情、卡片详情、文件查看和待推送预览统一增加本地修改入口，可直接打开对应变更文件。

### 市场、插件与工具管理

- 市场 Skill 详情新增完整文件树和文件内容预览，并可直接从详情弹窗安装。
- Cursor 插件新增启用/停用能力，可从插件列表或工具管理弹窗操作，并提示重载 Cursor 后生效。
- 工具管理弹窗新增插件列表、搜索、启停和批量操作，并显示 Skill、MCP、插件各自的启用统计。
- Skill 和 MCP 卡片新增一键启用到全部支持工具的操作，并显示部分启用进度。
- 插件支持直接打开真实文件夹，并增强同一插件跨 Claude Code、Codex、Cursor 宿主的聚合识别。
- 设置页新增打开 SkillDock 配置存储目录的入口；没有可用编辑器时，可直接使用系统文件夹作为默认打开方式。

## 优化

### UI 与交互细节

- 全面调整字体层级、字号、字重、行高、间距、圆角和信息密度，使列表、卡片、详情和设置页的视觉层次更清晰。
- 统一 Skills、MCP、插件和安装页的搜索框、工具栏、来源切换器、布局切换器与操作按钮样式。
- 优化主操作按钮、下拉选择器、Popover、Tooltip 和弹窗按钮的浅色/深色语义及悬停、聚焦、禁用状态。
- 优化弹窗边界、浮层方向和顶部安全区，避免菜单、提示和操作区被窗口边缘裁切。
- 统一文件树、代码预览、Diff 预览和详情区域的滚动条样式。
- 优化卡片信息布局：长描述保持完整数据并由界面截断，最多展示六个已启用工具，停用状态使用更清晰的中性色。
- 优化 Skills、MCP 和插件页面的紧凑页头、来源导航和工具栏排列；切换来源后自动回到列表顶部。
- 优化默认窗口尺寸及跨平台小屏显示；修复并改善 macOS 标题栏空白区域双击行为。

### 文件与差异预览

- 重新设计 Skill 与插件文件预览界面，优化文件树层级、详情布局、操作入口和加载状态。
- 新增更现代的文件类型图标，并增强 Markdown、JSON、YAML、JavaScript、TypeScript、Rust 等常见文件的语法识别和高亮。
- 市场文件树改为按需加载文件内容，在读取失败时提供紧凑、明确的错误状态。
- 统一普通文件预览、本地修改预览和待推送变更预览，减少重复入口和视图跳转。

### 状态、刷新与管理体验

- 优化 Skill 来源导航和托管状态统计，紧凑模式下可通过“更多”快速选择其他已安装工具。
- 优化 Skill、MCP、插件启停后的列表稳定性，操作完成后保持原有顺序，避免项目跳位。
- 优化后台 Git 状态刷新，更新单个或全部 Skill 时不再被较早启动的刷新结果覆盖。
- 优化启动时的布局偏好读取，减少来源视图和页头布局闪烁。
- 优化真实目录 Skill 的简介读取，优先展示 `SKILL.md` 中的实际描述。
- 自动更新检查增加超时和失败提示，网络异常时更快返回明确结果。
- 优化插件跨宿主来源识别、Codex 插件检测、本地安装列表滚动和商店默认排序。

## 修复

- 修复 Windows 下路径分隔符、混合路径、子进程调用和目录打开等兼容问题。
- 修复 Windows Skill 符号链接/目录联接的创建、检测、同步与安全删除问题，避免误删真实来源目录。
- 修复 Windows 打开带查询参数的授权地址时参数可能被截断的问题。
- 修复 Windows 工具安装检测、打包配置、应用图标、无框窗口安全区和外部链接打开问题。
- 修复后台刷新可能覆盖刚完成的 Skill 更新状态，以及批量更新后状态回退的问题。
- 修复 Skill、MCP 或插件启停后列表顺序变化、选中项跳动的问题。
- 修复来源布局启动闪烁、来源切换后滚动位置残留及紧凑选择器宽度不足的问题。
- 修复 Codex 兼容与插件识别异常，以及部分商店内容展示不完整的问题。
- 修复本地安装列表滚动、搜索框浏览器自动补全和插件工具栏贴近原生窗口边缘的问题。
- 修复弹窗浮层裁切、顶部 Tooltip 被遮挡、文件编辑区聚焦边框和预览滚动条显示问题。
- 修复 macOS 标题栏空白区域双击未按系统设置执行，以及旧版应用存储路径残留问题。
