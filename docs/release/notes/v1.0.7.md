## 新增

- 支持连接 GitHub 账号，并使用私有仓库备份 SkillDock 数据。
- 支持备份和恢复 Skills、MCP、插件、启用状态及便携偏好设置，敏感凭据不会上传。
- 支持查看、恢复和隐藏云端历史备份节点，并显示备份与恢复进度。

## 修复

- 修复新设备从云端同步时可能长时间停留在处理中或恢复不完整的问题。
- 修复 GitHub 登录、验证码自动复制及退出连接后的授权状态问题。
- 修复已隐藏的 Skill 市场仍参与全局搜索并显示加载错误的问题。

## 优化

- 开启云端备份时仅关联或创建备份仓库，由用户主动执行首次备份。
- 优化 GitHub 连接、备份操作、历史节点及通知区域的界面和提示。
- 优化 GitHub API 限流提示，未登录或额度不足时可直接前往账号设置。
