## 新增

- SkillDock 工作区采用新的 `data`、`cache`、`logs` 和 `credentials` 等目录结构，并自动迁移旧数据。
- 插件新增文件浏览、编辑、Git 差异预览与逐块回退，并展示待提交、待推送和可更新状态。
- SkillDock 托管插件以 `~/.skilldock/plugins` 为唯一源目录并保护共享源文件，为 Cursor、Codex 生成实体运行副本，并在连续 10 秒无改动后聚合同步。

## 修复

- 修复 MCP 市场安装后未同步到受支持应用的问题，兼容 BOM、保护已有或损坏配置，并隔离逐应用失败。
- 修复外部 Git 操作后 Skill 与插件状态不及时刷新，以及旧异步结果覆盖新状态的问题。
- 修复工作区迁移后的设置路径、应用更新提示、未托管 Skill 详情和 SkillHub 发布工作台交互。
- 修复 Windows 插件宿主命令误判、Cursor 跨目录软连接内容无法加载，以及 Claude Code 删除后的注册与缓存残留。
- 修复插件部分安装状态、本地更新时间、弹窗层级、更新错误通知和本地变更数量角标等问题。
