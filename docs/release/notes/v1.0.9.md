## 新增

- SkillDock 托管插件现在以 `~/.skilldock/plugins` 为唯一源目录，并为 Cursor 和 Codex 生成可直接加载的实体运行副本。
- 托管插件发生本地修改后，会在连续静默 10 秒后聚合刷新 Cursor 和 Codex 运行副本，减少频繁重复同步。

## 修复

- 修复 Cursor 无法加载跨目录软连接插件内容的问题，并在插件更新后重建 Cursor 与 Codex 的实体副本。
- 修复 Claude Code 删除插件后遗留安装记录、启用状态、市场清单和旧缓存的问题。
- 修复插件安装部分成功或失败后，已安装宿主状态未及时刷新的问题。
- 修复插件首次安装及后续修改时本地更新时间不准确的问题。
- 修复插件更新错误同时占用页面区域的问题，统一改为全局通知提示。
- 修复插件详情弹窗“本地变更”按钮未显示变更文件数量角标的问题。
