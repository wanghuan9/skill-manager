## 新增

- Skills 工作区新增轻量级标签快速筛选，支持在下拉筛选面板与平铺标签栏之间切换，并默认使用更紧凑的下拉面板。
- 标签筛选统一纳入来源方式、托管方和自定义标签，可按来源或标签快速定位 Skill。

## 优化

- Skill 与插件列表优先展示已启用项，并在同一状态内按本地更新时间降序排列，同时保持操作后列表位置稳定。
- 优化标签颜色、图标尺寸、列表与卡片布局，以及分组来源的本地路径聚合规则。
- 完善发布页和设置页的英文界面适配。

## 修复

- 修复标签在切换页面或重启后丢失、连续给多个 Skill 添加标签时互相覆盖的问题。
- 修复市场安装来源未持久化后被识别为 Git，以及本地 Skill 被拆分成多个来源分组的问题。
- 修复插件更新后本地更新时间未刷新，以及设置页事件监听释放时偶发报错的问题。
